# CodeAlpha Java Task 4 – Hotel Reservation System

## About the Project
This project is developed as part of the CodeAlpha Java Internship.

The Hotel Reservation System is a Java-based application that allows users to view available rooms, search rooms by category, book rooms, cancel reservations, and view booking details.

## Features
- View available rooms
- Search rooms by category
- Book a hotel room
- Calculate the total booking amount
- Select a payment method
- Generate a booking ID
- View booking details
- Cancel reservations
- Save booking and cancellation details to a file

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- ArrayList
- File Handling
- Exception Handling

## How to Run
1. Download or clone this repository.
2. Open the project in VS Code or any Java IDE.
3. Compile the Java file.
4. Run the `HotelReservationSystem` class.
